# 대경지역 허용인시 현황 도구 — 사용 안내

## 이 도구가 하는 일
본사에서 매월 주는 `허용인시.xlsx` 파일을 기반으로, 매장별 목표 대비 예상마감·잔여인시를 한눈에 볼 수 있는 정적 웹페이지(index.html)를 만듭니다.
- **전체 매장 현황**: 매장별 목표, 근로형태별 인원수(입력 가능), 잔여인시(월) / 잔여인시(월평균)
- **개별 매장 확인**: 매장의 일자별 매출현황 파일을 올리면 예상진도율·예상마감금액·85% 기준 매출금액·85% 대비 과부족금액을 실시간 계산

인원수를 입력하거나 매출 파일을 올리는 모든 계산은 브라우저 안에서만 이루어지고 외부로 전송되지 않습니다.

---

## 매월 갱신하는 방법
새 달의 `허용인시.xlsx` 파일을 대화에 첨부하고 "새로 만들어줘"라고 요청하시면, 새 `index.html`을 만들어 드립니다. 파일의 행·열 위치가 바뀌어도 **헤더 이름으로 항목을 찾기 때문에** 문제없이 처리됩니다.

### 파일에 꼭 있어야 하는 항목 (헤더 이름 기준)

| 항목명(헤더) | 용도 |
|---|---|
| 점명 | 매장 구분 |
| 목표 | 이번 달 목표금액 (85% 기준금액·진도율 계산) |
| 인시생산 | 예상마감 추정 및 허용인시(매출기준) 계산 |
| 허용인시(매출) | 매출 파일 업로드 전 "예상마감" 초기값 추정용 |
| 허용인시(월평균) | 잔여인시(월평균) 계산 |
| OT | 정규직 표준시간(168+OT) 계산 |
| 정규직 / 2D/8H / 3D/8H / 5D/4H / 5D/6H / 5D/8H | 인원수 입력칸 초기값 (매달 갱신 시 현재 인원으로 리셋) |

**열 순서와 표 위치는 상관없습니다.** 본사 출력본이든 직접 쓰시는 관리 워크북(9월 예상 인시 운영테이블)이든, "점명" 헤더가 있는 표를 찾아 읽습니다. 매장명 표기(예: "FH 대구동성로중앙점")는 기존과 동일하게 써주셔야, 개별 매장 확인란에서 올리는 "일자별 매출현황" 파일의 열 이름과 정확히 매칭됩니다.

### 지금은 쓰지 않는 항목
**허용인시(전체)**, **허용인시(단시간)** — 파일에 남아있어도 무시되며, 없어도 상관없습니다.

## 업로드 파일 2종 (상단)
1. **전 매장 일자별 매출현황(금액)** — 22개 매장이 한 파일에 들어있는 파일. 올리면 지역 합계와 모든 매장 값이 계산됩니다.
2. **기간별 매출분석(채널)** — **몰입점 13개점의 재고통합 매출**을 더하기 위한 파일입니다. (가두점은 일자별 매출현황에 이미 재고통합이 합산되어 있어 사용하지 않음)
   - 반드시 **일자별 매출현황과 같은 기간**으로 조회해서 받아야 합니다. 기간이 다르면 화면에 경고가 표시됩니다.
   - 재고통합 매출은 경과일수로 나눠 **하루당 같은 금액**으로 평일/휴일에 더해 예상마감에 반영됩니다. (기존 관리 워크북과 같은 방식)
   - 몰입점(재고통합이 일자별 매출에서 가려진 매장) 13곳: KM 4곳, SE 3곳, SP 대구동성로점, ST 5곳(구미롯데마트·김천롯데마트·대구현대아울렛·성서홈플러스·율하롯데아울렛)
   - 이 파일을 올리지 않으면 몰입점 예상마감은 재고통합이 빠진 채(낮게) 계산되고, 경고 문구가 표시됩니다.

## 개별 매장에서 매출 파일 올릴 때
"개별 매장 확인" 섹션에서 매장을 고른 뒤 그 매장의 **일자별 매출현황(금액)** 파일을 올리면:
- 올리기 전: 본사 파일의 허용인시(매출) 값을 역산한 추정치가 표시됩니다.
- 올린 후: 그 달 평일/휴일 매출 추이를 바탕으로 실시간 예상마감을 다시 계산합니다.

## 공휴일 반영
토·일요일과 2026년 대한민국 법정 공휴일(대체공휴일 포함)이 자동으로 "휴일 패턴"에 반영되어 예상마감 계산에 쓰입니다. **2027년으로 넘어가면 공휴일 목록을 갱신해야 하니, 연말쯤 알려주세요.**

## 변경 요청하는 방법
표시 항목이나 배치, 계산 방식 등 더 편하게 바꾸고 싶은 부분이 있으면 언제든 말씀해주시면 반영해드립니다.
